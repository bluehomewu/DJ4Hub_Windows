# DJ 4G Hub for Windows v1.8.1

[English](#english) · [繁體中文](#繁體中文)

## English

The first Windows release of DJ 4G Hub. It manages SMS, calls, eSIM, mobile data and AT debugging through the existing USB interfaces of the DJI 4G module (USB `2ca3:4006`, Quectel QDC507), without modifying the module firmware. The interface is in Traditional Chinese (Taiwan).

> This is an unofficial, independent project, not authorized by DJI, Quectel or any carrier. Ported from [WongLoki/DJ4Hub](https://github.com/WongLoki/DJ4Hub) (commit `3914cd6`) and licensed under the PolyForm Noncommercial License 1.0.0. Commercial use is not permitted.

### Highlights

#### Calls
- **Make and answer calls on the computer**: VoLTE dialing, answering, hanging up and voice-menu keys, with call audio through the computer's microphone and headset.
- **Incoming-call pop-up**: when a call comes in, a window of about 420×720 opens in the bottom-right corner with a phone-style layout. While ringing it shows the caller with Decline and Accept; during a call it offers Mute, Keypad and a hang-up button pinned to the bottom, and it closes itself when the call ends. `dj4ghub phone` opens the same window as a dialer at any time.
- **Background standby**: the service keeps module audio ready, so calls can be answered with computer audio without an open web page. It can be turned off on the phone page.
- **Keypad**: types the number when idle and sends DTMF tones during a call.

#### SIM and network
- **SIM and VoLTE panel**: shows:
  - IMS configuration and registration, and whether VoLTE is usable
  - SIM initialization, issuing network and SMS center
  - Home or roaming registration
  - Band, bandwidth, RSRP/RSRQ/SINR and cell details

  ICCID and IMSI are masked by default.
- **SIM PIN unlock**: enter the PIN in the panel, which shows the remaining attempts. It asks for confirmation before the last attempt and never logs the PIN.
- **Windows Mobile Broadband**: with `usbnet=0` and the Quectel NDIS/MBIM driver, SMS and mobile data work at the same time. The console can connect the Mobile Broadband interface and enable a disabled adapter (UAC prompt). The internet check is forced through the module's adapter.

#### SMS
- Send and receive SMS, with long messages split and reassembled automatically. Verification codes are detected in both Simplified and Traditional Chinese.
- **Messages stay on the module by default** and are also archived locally, so the inbox survives restarts. To delete module messages after archiving, start with `dj4ghub start --sms-cleanup`.

#### Usability
- Double-click `dj4ghub.exe` to start in the background and open the console. Commands: `start / stop / status / logs / open / phone / activate`.
- Text size and layout are tuned for large Windows displays.
- Reloading the page keeps the current section.
- Call and SMS alert sounds are on by default.

### Requirements

- Windows 10/11 (x64; ARM64 can be built from source)
- Quectel Windows USB driver (Device Manager should list "Quectel USB AT Port")
- Mobile data: NDIS or MBIM driver (`usbnet=0`), or ECM driver (`usbnet=1`)
- Computer call audio (optional):
  - Android Platform Tools (`adb.exe`)
  - The three hash-pinned MaVo files, imported with `dj4ghub audio-install`
  - First use permanently enables ADB on the module and reboots it once
- Calls: a SIM with VoLTE support

### Installation

1. Download `DJ-4G-Hub-1.8.1-windows-amd64.zip` and verify its SHA256:
   ```
   1ae08ca2f709102838e3a4db14924de37e1b15556e6f4b9556c1c97aa3dedc71
   ```
   ```powershell
   Get-FileHash -Algorithm SHA256 .\DJ-4G-Hub-1.8.1-windows-amd64.zip
   ```
2. Extract it and double-click `dj4ghub.exe`. The browser opens `http://127.0.0.1:7575`.
3. If the SIM needs a PIN, unlock it in the "SIM 與 VoLTE" panel on the overview page.

### Notes

- **Use a headset for calls**: the service sends the computer microphone to the module directly, without echo cancellation.
- When the module's sound card appears, Windows may make it the default playback or communications device, which affects apps such as Teams or LINE. Change it back under Settings → System → Sound, or turn off background standby on the phone page.
- Do not let another adb server hold the module. If you ran `adb devices`, run `adb kill-server` first.
- The module does not detect a SIM inserted after power-up; restart the module.
- The executable is not code-signed, so SmartScreen may warn on first launch.

### Not yet verified

- Long calls
- Recovery after the computer sleeps
- Switching to `usbnet=1` (ECM) data mode
- Settings UI for cloud backup of the communication history (not available on Windows yet)

### Verified on hardware

Windows 11, QDC507GLEFM21 and a Chunghwa Telecom SIM:
- SIM PIN unlock and IMS/VoLTE registration
- Two-way outgoing and incoming calls
- Incoming-call pop-up and background standby
- Receiving SMS and writing them back to the module
- Mobile Broadband internet check

## 繁體中文

DJ 4G Hub 的第一個 Windows 版本。透過 DJI 4G 模組（USB `2ca3:4006`，Quectel QDC507）原有的 USB 介面，在 Windows 上管理簡訊、通話、eSIM、行動網路與 AT 除錯，不修改模組韌體。介面為繁體中文（台灣用語）。

> 本專案為非官方的獨立專案，未獲 DJI、Quectel 或電信業者授權。移植自 [WongLoki/DJ4Hub](https://github.com/WongLoki/DJ4Hub)（commit `3914cd6`），遵循 PolyForm Noncommercial License 1.0.0，不得作商業用途。

### 重點功能

#### 通話
- **用電腦打電話與接電話**：VoLTE 撥號、接聽、掛斷、語音選單按鍵，通話音訊走電腦的麥克風與耳機。
- **來電彈出小視窗**：有來電時，在螢幕右下角開啟約 420×720 的通話視窗，介面仿手機：
  - 響鈴時顯示大號碼與「拒接／接聽」。
  - 通話中可靜音、開鍵盤，最下方固定掛斷鍵。
  - 通話結束後自動關閉。

  也可用 `dj4ghub phone` 隨時開啟撥號視窗。
- **背景待機**：服務自行維持模組音訊就緒，不必開著網頁也能用電腦接聽；可在電話頁關閉。
- **數字鍵**：沒有通話時可直接輸入號碼，通話中送出按鍵音。

#### SIM 與網路
- **SIM 與 VoLTE 狀態面板**：顯示以下資訊，ICCID、IMSI 等預設遮蔽：
  - IMS 設定與註冊、VoLTE 是否可用
  - SIM 初始化、發卡業者、簡訊中心
  - 本地／漫遊註冊
  - 頻段與頻寬、RSRP／RSRQ／SINR、基地台資訊
- **SIM PIN 解鎖**：在面板中輸入 PIN 解鎖，顯示剩餘嘗試次數；最後一次嘗試前會再次確認，PIN 不會被記錄。
- **Windows 行動寬頻**：`usbnet=0` 搭配 Quectel NDIS／MBIM 驅動即可同時收發簡訊與上網。主控台可連線行動寬頻、啟用停用中的網卡（UAC），網際網路檢測會強制走模組網卡。

#### 簡訊
- 收發簡訊、長簡訊自動分段與重組、驗證碼自動辨識（簡體與繁體都支援）。
- **預設保留模組上的簡訊**，同時存入本機紀錄；重新啟動後收件匣不會清空。需要存檔後自動清除模組簡訊時，以 `dj4ghub start --sms-cleanup` 啟動。

#### 使用體驗
- 雙擊 `dj4ghub.exe` 即在背景啟動並開啟管理網頁；提供 `start／stop／status／logs／open／phone／activate` 指令。
- 字級與版面針對 Windows 大螢幕調整。
- 重新整理後停留在原本的頁面。
- 來電／簡訊提示音預設開啟。

### 系統需求

- Windows 10／11（x64；另可自行建置 ARM64）
- Quectel Windows USB 驅動程式（裝置管理員應出現「Quectel USB AT Port」）
- 行動上網：NDIS 或 MBIM 驅動（`usbnet=0`），或 ECM 驅動（`usbnet=1`）
- 電腦通話音訊（選用）：
  - Android Platform Tools（`adb.exe`）
  - 以 `dj4ghub audio-install` 匯入 3 個固定雜湊的 MaVo 檔案
  - 第一次使用時會永久開啟模組 ADB，並重啟模組一次
- 電話與 VoLTE：SIM 需支援 VoLTE

### 安裝

1. 下載 `DJ-4G-Hub-1.8.1-windows-amd64.zip`，核對 SHA256：
   ```
   1ae08ca2f709102838e3a4db14924de37e1b15556e6f4b9556c1c97aa3dedc71
   ```

### 注意事項

- **通話請戴耳機**：電腦麥克風到模組這一段由服務直接處理，沒有回音消除。
- 模組音效卡出現時，Windows 可能把它設為預設的播放或通訊裝置，影響 Teams、LINE 等軟體；需要時到「設定 → 系統 → 音效」改回，或在電話頁關閉背景待機。
- 執行時請勿讓其他 adb 服務佔用模組；若執行過 `adb devices`，請先執行 `adb kill-server`。
- 開機後才插入的 SIM 卡，模組不會自動偵測，需要重啟模組。
- 執行檔未經程式碼簽章，首次執行時 SmartScreen 可能提示。
