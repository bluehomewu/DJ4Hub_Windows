## English

Changes since [v1.8.1](https://github.com/bluehomewu/DJ4Hub_Windows/releases/tag/v1.8.1). See the v1.8.1 notes for the full feature overview, requirements and known limitations.

### New

- **Import eSIM activation codes from QR code images** (eSIM / 卡片 → 下載新 Profile):
  - Paste a screenshot or image with Ctrl+V.
  - Choose an image in the file dialog.
  - Drag an image onto the import area.
  - Paste an `LPA:1$...` activation code as text.

  The SM-DP+ address and matching ID are filled in automatically, and you are asked for a confirmation code when the QR code requires one. Nothing is downloaded until you press the download button. Decoding runs locally with the embedded jsQR library (Apache-2.0), so it also works offline.
- **AT command reference** on the AT 除錯 page: 48 commands grouped by topic, with parameters written as `{a | b}` (choose one) and `[ ... ]` (optional), a risk label (read-only, changes settings, needs reboot, high risk) and a search box. Clicking a command only fills the input and selects the first parameter; it never runs the command.
- **Version and GitHub link** in the sidebar footer, replacing "Local-first · USB control".

### Fixed

- The connected-device label now reads 裝置在線.
- Changing the `#page` part of the address, or using back and forward, now switches the page.

## 繁體中文

自 [v1.8.1](https://github.com/bluehomewu/DJ4Hub_Windows/releases/tag/v1.8.1) 以來的變更。完整功能介紹、系統需求與已知限制請參考 v1.8.1 的說明。

### 新功能

- **從 QR Code 圖片匯入 eSIM 啟用碼**（eSIM / 卡片 → 下載新 Profile），支援以下方式：
  - 按 Ctrl+V 貼上截圖或圖片
  - 從檔案總管選擇圖片
  - 把圖片拖曳到匯入區
  - 直接貼上 `LPA:1$…` 啟用碼文字

  讀取後會自動填入 SM-DP+ 位址與 Matching ID；若 QR Code 標示需要確認碼，會提示輸入。按下「開始下載」之前不會執行任何下載。解碼在本機以內建的 jsQR 函式庫（Apache-2.0）進行，離線也能使用。
- **AT 指令參考**（AT 除錯頁）：48 條指令依類別分組，參數以 `{a | b}`（擇一）與 `[ … ]`（可省略）標示，並註明唯讀、修改設定、需重啟、高風險，可搜尋。點選只會填入輸入框並選取第一個參數，不會自動執行。
- **左下角顯示版本號與 GitHub 連結**，取代原本的「Local-first · USB control」。

### 修正

- 裝置連線狀態改為「裝置在線」。
- 修改網址中的 `#頁面`，或使用瀏覽器上一頁／下一頁時，頁面會跟著切換。
