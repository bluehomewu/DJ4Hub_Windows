# 撥號失敗診斷

撥號或接聽指令失敗後，後端依次讀取 `AT+CEER`、`AT+QCFG="ims"`、`AT+QCFG="usbcfg"`。每項查詢逾時為 2 秒；唯讀取，不寫設定、不重啟、不重撥。失敗原因是一次盡力取樣，背景 AT 查詢或韌體行為可能影響 CEER，不能視為精確網路側信令記錄。

服務日誌搜尋 `call_action_failed`，包含動作、耗時、協定結果、錯誤及診斷快照。快照只保留白名單協定行，排除電話號碼回顯、CLCC 和簡訊通知；查詢失敗記為 `query_failed`，不推斷功能已關閉。用戶端仍收到原始失敗說明，附帶同一快照。

`ims=0,0` 的第一個 0 是沿用 MBN 預設設定，不是強制關閉；設定讀取不代表 IMS 註冊狀態。USB 語音位為 0 是調查線索，不作為本版本阻止撥號的依據。音訊待機也不證明電信業者通話可用。

本版本沒有自動開啟 IMS/UAC。音訊初始化支援原始 RMNET/ECM 組合及其末尾帶單個 audio 的組合，不重複追加 audio，停止時恢復進入工作階段前的 USB functions 並關閉音訊流。

2026-09-13 單變數實驗：在確認無語音通話、儲存本機私有設定備份後，僅將 DJI 裝置 usbcfg 末位 UAC 從 0 改為 1，嚴格讀回後執行 CFUN 重啟。重啟後讀取到 diag,serial,ecm,ffs,audio，root 為 0、核心 3.18.44；IMS 仍為 0,0，usbnet 仍為 1，CGDCONT 與備份一致。該設定已保留在本次測試裝置上；不是刷韌體，也沒有加入所有新裝置的自動寫入流程。實際電信業者呼叫仍需測試，不能以 USB 介面列舉成功替代。
